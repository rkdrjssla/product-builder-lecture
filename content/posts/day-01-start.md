## 시작하게 된 계기

막연하게 '부업으로 뭔가 해보고 싶다'는 생각을 갖고 있었다. 그러다 Claude Code라는 AI 코딩 도구를 알게 됐고, 이걸로 실제로 뭔가 만들어보기로 했다.

목표는 단순하다.

1. 블로그를 직접 만들고
2. 그 블로그에 올릴 콘텐츠를 자동화하는 툴을 만들고
3. 그 툴을 상품화한다

일석삼조를 노리는 계획이다.

## 오늘 한 일

Claude Code와 대화하면서 Next.js 블로그를 처음부터 만들었다. 내가 한 건 사실상 없다. 어떤 블로그를 만들고 싶은지 말했을 뿐인데, Claude가 알아서 프로젝트를 세팅하고 파일을 만들었다.

```
블로그 구조:
- content/posts/    ← 마크다운으로 글 작성
- src/app/          ← Next.js 페이지들
- src/lib/posts.ts  ← 포스트 파싱 로직
```

## 느낀 점

생각보다 훨씬 빠르다. 보통 이런 세팅을 혼자 하려면 반나절은 걸렸을 텐데, 30분도 안 걸렸다.

다음 목표는 이 블로그를 Vercel에 배포하고, Claude API를 이용해서 글 초안을 자동 생성하는 파이프라인을 만드는 것이다.
